# Menus de la semaine

Générateur de menus du foyer : une seule page (`index.html`), sans installation.

- On indique ce qu'il reste dans le frigo : ces aliments sont utilisés dès les premiers jours.
- Les jours de cantine, le panier repas reprend le dîner de la veille, choisi pour être facile à transporter et à réchauffer.
- Liste de courses, idées de dessert / goûter, impression en noir et blanc.
- Les menus validés sont mémorisés sur l'appareil pour éviter les répétitions.

Pour l'utiliser en ligne : Settings → Pages → Branch `main` → Save.
